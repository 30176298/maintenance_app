    API-->>SM: 15. 200 OK + data
    SM->>DB: 16. UPDATE if !isDirty<br/>&& server.updatedAt > local.updatedAt
    SM-->>UI: 17. Sync complete
    UI-->>User: 18. Update UI

        Note over User,SDB: ✓ Data synchronized across all devices
    end
